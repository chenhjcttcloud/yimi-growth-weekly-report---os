# 周报质量与360协同得分导出

管理员和老板在「周报质量」「360协同得分」页面点击「导出Excel」，下载对应月份的 `.xlsx`。评分工作台「得分结果」中导出一个包含两类工作表的文件。

导出沿用当前部门和员工搜索条件，包含全部匹配分页，不限于当前8人或右侧选中的员工。文件名标明月份、部门和是否使用搜索筛选。没有匹配员工、月度数据尚未加载或正在切换月份时不能导出。

## 数据口径

- 周报质量：最终分、AI质量均分、已分析均分、质量状态、应交／已交／缺交数量、计入质量／已分析／待分析数量。质量计入数量是已提交且有效的报告数量，独立于应交数量。月结及收集、分析完成后自动生成最终分；历史最终分保留原值。
- 360协同得分：2026-11 起导出同事互评100%的已发布最终分、互评均分与进度、缺评数量及计分口径，不含负责人或老板30%列。旧月份保留30%／70%字段；同月混有已发布旧口径结果时，30%列注明为历史字段，新口径员工对应单元格留空。未完成的均分只作当前参考，不能当作最终分。
- 两类导出表格均不包含确认人、确认时间、发布人、发布时间、生成方式及结果来源等审核列。后台历史记录继续保留。
- 有效零分为数值0；缺失分数为空单元格，并以状态说明原因。计数使用整数显示，分数显示一位小数。
- 已发布最终分与分项使用已保存结果，不重新计算。历史口径只保留原最终分，缺少的历史30%／70%分项和进度留空，不套用当前配置。
- 每个员工使用稳定员工ID区分，同名人员及其他月份的趋势记录不会混入当前月份。

导出只读取页面已加载的管理数据快照，不额外调用总览、明细、AI或发布接口，不修改业务数据。不包含周报正文、AI证据、互评评论或其他员工的全轮待评名单。普通员工页面不提供管理汇总导出。

文件在浏览器本地生成并下载，不上传到外部服务、不在服务器保存导出文件。所有文本写为Excel字符串，不作为公式执行。表头支持筛选、冻结及合理列宽；下载开始不等于浏览器已完成保存。

## 验证

`node scripts/test-xlsx-workbook.mjs` 验证文件结构、CRC、XML、零分／空值与公式文本；`node scripts/test-performance-score-export.mjs` 验证字段口径及历史结果；`node scripts/test-performance-export-ui.mjs` 使用合成数据检查权限、月份、筛选、实际下载和失败处理。
