## 修复内容

| 问题 | 修复后的行为 |
|---|---|
| 前任负责人已被老板评分后，新任负责人无法评分 | 新记录以部门、月份、被评人共同标识；老板可给新任负责人独立评分，前任分数和发布结果保留 |
| 人员晋升导致已提交的负责人评分失效 | 当月已经提交的评分责任计划继续使用；新岗位不会重复计入30% |
| 飞书个人令牌过期后任务和公司群发送失败 | 令牌保存在服务端加密库，按会话绑定；自动续期，更新轮换后的令牌，并发续期合并，重启后保留 |
| 授权撤回、续期到期或刷新回执丢失 | 明确返回重新授权状态，页面提供入口；不偷偷改为机器人或其他用户发送 |
| 周报提醒和授权预警依赖容器没有的CLI | 统一使用应用身份HTTP消息接口；保留已配置的发送开关。旧配置指定自动用户身份时明确拒绝，不冒用身份 |
| 周报提醒异常及重复发送 | 修复未定义变量；使用当周稳定标识、发送前记录pending、不明确回执记uncertain，刷新/重启不自动重发；使用user_id和在职花名册，不用姓名/邮箱替换身份 |
| 公司消息重复提交或不明确回执 | 发送前领取唯一记录，同内容重复请求复用成功记录；pending/uncertain禁止再次发送，失败重试保留记录ID |
| 成功同步通讯录时SSO登录失败 | 空同步备注安全保存为空字符串，避免NOT NULL约束失败；停用账号不因SSO自动恢复 |
| 缺少旧评分快照数组时管理页白屏 | 对缺失或非数组字段统一使用空数组；不生成虚构分数 |
| 取消点赞删除原始记录 | 使用状态覆盖层保留原始点赞记录，同时正确统计当前可见点赞 |
