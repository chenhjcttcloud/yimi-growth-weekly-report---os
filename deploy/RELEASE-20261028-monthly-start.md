# 月末评分提醒从 2026 年 11 月起生效

用户于 2026-10-28 明确要求开启生产环境月末评分提醒，随后补充“下个月才开始”。本次仅为该项配置提供生效月份保护并启用。

- 生产镜像：`emie-growth-os:production-20261028-monthly-start`。
- SQLite 配置键：`month_end_score_reminders`，`enabled: true`、`time: 10:00`、`startMonth: 2026-11`。
- 时间口径：北京时间，每月最后两个工作日各提醒一次，发送前重新检查未评分任务；已完成、停用或结果已发布的不提醒。
- 首个生效月日期：2026-11-27、2026-11-30。2026 年 10 月不发送，不补发。
- 设置入口：系统设置 → 周期与提醒 → 月度评分飞书提醒，可查看开关、时间、生效月份、预览名单和发送记录。
- 提醒包含同事互评、负责人给下属月评、老板给部门负责人评分。不会自行生成同事评分关系或开启未发起的周期。
- 生效月份持久化在数据库中，重启仍有效；旧客户端仅保存开关或时间时保留已设定月份。默认预览首个尚未开始的生效月份。

验证包含设置校验及持久化、旧客户端兼容、10 月两次到期均跳过且不创建投递、11 月生效、API 权限、浏览器保存及刷新、工作日日历与重复发送保护。生产数据隔离副本使用无网络容器预检，验证启用后默认预览 11 月、日期准确、10 月跳过、消息投递记录为 0。
